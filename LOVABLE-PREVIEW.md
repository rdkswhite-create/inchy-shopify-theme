# INCHY Lovable design

Connect the branch `draft/lovable-clinical-homepage` in Shopify's theme library. The new design is the default homepage on this branch. It is also available as the `page.lovable` page template.

The reference's original imagery, Inter fonts, responsive classes, section order and copy are bundled in the theme. No Lovable preview token or runtime is required.

The theme editor exposes the tagline and nutrition figures. The reference's 66% protein and 14% fibre are retained; these are editable independently of the design.

Shop links to Shopify's product collection and Cart opens Shopify's cart page. Registration uses Shopify's native customer newsletter form, with success/error feedback and the tag `inchy-us-launch`. Payment icons reflect the store's enabled payment types rather than promising unavailable payment methods.

The existing product, collection and cart templates remain available. This branch does not publish or change the live theme.
